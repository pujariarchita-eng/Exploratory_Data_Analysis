# Exploratory Data Analysis (EDA) - Student Performance

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Student Performance dataset using Python, Pandas, NumPy, and Matplotlib.

The project focuses on understanding dataset structure, cleaning data, calculating statistical measures, creating visualizations, and identifying meaningful patterns.

## Objective

To combine data exploration, data cleaning, statistical analysis, and visualization into a basic EDA workflow.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset Description

The dataset contains student information, including:

- Student ID
- Study Hours
- Attendance
- Previous Score
- Sleep Hours
- Final Score

The Python code generates sample data automatically for practice. It also introduces missing values and a duplicate row to demonstrate data cleaning.

Note: The generated dataset is illustrative and does not contain real student records.

## Project Workflow

1. Load and explore the dataset.
2. Display the first five rows.
3. Check dataset shape and data types.
4. Calculate descriptive statistics.
5. Identify missing values and duplicate rows.
6. Remove duplicate records.
7. Fill missing numeric values using the median.
8. Create four meaningful visualizations.
9. Calculate statistical measures and correlation.
10. Record observations and export the cleaned dataset.

## Visualizations

### 1. Distribution of Final Scores
A histogram showing the distribution of students' final scores.

### 2. Study Hours vs Final Score
A scatter plot used to explore the relationship between study hours and final scores.

### 3. Average Score by Attendance
A bar chart comparing average final scores across attendance groups.

### 4. Correlation Matrix
A visualization summarizing correlations among numerical variables.

Install Python 3.9 or later.

Run the following command:

bash

### Step 3: Run the Python File

bash
